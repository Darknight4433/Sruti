Add Sruti to Your Discord Server

One-click install. Pick your server from the Discord popup, click Authorize, and start playing music with /play!

🔐 Required Permissions

  • Connect & Speak in Voice Channels
  • Send Messages & Embed Links
  • Use Slash Commands (applications.commands)
  • Server Members Intent (role checking)

⚡ Available Slash Commands

  • /play <query> — Play YouTube or search
  • /controls — Personal interactive control panel
  • /queue — Interactive queue with jumps
  • /history & /library — Shared libraries
  • /status & /restart — System commands

To authorize this bot on a Discord server, you must have the Manage Server or Administrator permission in that server.
